# **App Name**: NeoPulse Events

## Core Features:

- Authentication & Profile UI: User interface for Sign In modal/page (Email + OTP style), profile editing, theme toggling, and signing out.
- Dynamic Navigation System: Fixed glassmorphic top navbar with a glowing 'DJ SANJAY' logo and social links, plus a responsive bottom navbar with neon glow for main app sections.
- Spectacular CDJ Jog Wheel: A large, realistic, and animated spinning vinyl jog wheel in the bottom navigation with glowing BPM display, play/pause (click), and next song (long press) functionality, synchronized with background music playback.
- Dynamic Homepage Layout: A visually strong homepage with hero section, animated event stats, engaging service showcase, and a review carousel, including interactive CTA buttons.
- Detailed Packages & Selection UI: Interactive display of Silver and Gold packages with all included items and add-ons as checkboxes, including a live price calculator.
- Guided Multi-step Event Booking Flow: A progress-tracked, multi-step UI for collecting event details (date, time, location, type), featuring various pickers and dropdowns, culminating in a beautiful invoice-style summary.
- AI-Enhanced Event Description Tool: A generative AI tool that suggests engaging, personalized event taglines or descriptions based on chosen booking details like event type and mood.

## Style Guidelines:

- Color Palette: Dark, premium nightclub theme. Primary UI elements will utilize a vibrant Neon Purple (#C026D3). The background will be a deep, dark purplish charcoal (#19161A), providing a sleek, moody foundation. Gold (#FACC15) will serve as a prominent accent for critical information and calls-to-action, while Cyan (#22D3EE) will highlight interactive elements and provide glowing effects, consistent with neon visuals from DJ flyers.
- Headline Font: 'Space Grotesk' (sans-serif), offering a modern, techy, and precise aesthetic. Body Font: 'Inter' (sans-serif), ensuring readability with a clean, objective, and neutral look suitable for various content lengths.
- Use sleek, minimalist icons, primarily from Lucide Icons, styled with neon glow effects in Cyan or Gold to complement the overall theme. Social media icons (Instagram, WhatsApp, Phone) should match this glowing style.
- Emphasize responsiveness with a mobile-first approach. Implement glassmorphic elements for fixed navigation bars (top and bottom). Utilize generous spacing and intentional alignment to convey a luxurious and high-end feel.
- Extensive use of Framer Motion for smooth transitions, hover effects, and micro-interactions. Key animations include a pulsating neon logo, animated numerical counters, a seamlessly rotating CDJ jog wheel, and subtle smoke/light particle effects (e.g., using tsParticles) in the hero section to enhance the nightclub ambiance.
